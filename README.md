
# Campus Helpdesk AI Agent

## About the Project
Campus Helpdesk AI Agent is a simple chatbot that answers common student questions about college facilities, academics, events, and campus services.

## Features
- Answers frequently asked questions
- Provides quick information to students
- Simple and user-friendly interface
- Supports editable questions and answers

## Technologies Used
- WordPress
- AI Chatbot

## How to Use
1. Open the chatbot.
2. Type a question related to the campus.
3. Read the answer provided by the chatbot.

## Project Purpose
The main goal is to help students get campus information quickly and easily.
